# 第三阶段：萤石设备套餐激活使用说明

## 1. 当前结论

平台已实现五个赛事套餐槽位、赛事权益摘要、管理员二次确认、真实设备与通道校验、幂等保护、Token 失效刷新、官方结果解析和数据库审计。赛事通知明确提供 5 个免费设备套餐，通知有效期为 6 个月；具体起止时间仍以萤石开放平台后台显示为准。当前没有萤石设备，因此只能验证槽位、安全边界和模拟接口；不会向萤石提交真实激活请求，也不能把套餐写成已激活。

赛事官方说明的激活接口为：

```text
POST https://open.ys7.com/api/v3/mall/device/package/code/active
```

请求需要有效 `accessToken`、套餐激活码、真实设备序列号和通道号。只有 `meta.code=200` 且 `activeCode=0` 才算激活成功。参考：[赛事套餐激活说明](https://ezsuperfans.com/portal.php?mod=view&aid=716)。

## 2. 安全设计

- 浏览器只选择槽位、已同步设备和通道，不提交完整激活码；
- 后端根据槽位读取 `services/api/.env`；
- API 只返回是否配置、激活码末四位和脱敏设备序列号；
- 数据库不保存完整激活码，只保存末四位；
- 同一个槽位或同一个设备通道只能建立一条审计记录；
- 在调用萤石前先写入 `pending` 记录，避免网络中断后盲目重复消耗激活码；
- 完整激活码、AppSecret 和 accessToken 均不会进入普通日志或前端。
- 权益摘要只返回槽位数、有效期、Token 状态、在线设备数和阻塞原因，不返回任何密钥正文。

## 3. 配置套餐槽位

只有准备好真实设备并核对套餐码时，才在 `services/api/.env` 中填写：

```dotenv
EZVIZ_PACKAGE_CODE_01=
EZVIZ_PACKAGE_CODE_02=
EZVIZ_PACKAGE_CODE_03=
EZVIZ_PACKAGE_CODE_04=
EZVIZ_PACKAGE_CODE_05=
```

槽位号必须和实际纸面或赛事发放清单一一对应。不要把真实值写入 `local.env.example`、README、截图或 Git。

赛事代金券需要从官方通知中的领取页面人工领取。领取完成并在平台后台核实后，可在 `services/api/.env` 记录：

```dotenv
EZVIZ_COUPON_REDEEMED=true
```

这个开关只表示团队已经人工确认领取，不会自动访问领取页面、消费余额，或开通云存储、AI、消息等收费服务。团队专属领取链接也不应写入 Git。

## 4. 启动

修改配置后停止旧 API，并在项目根目录运行：

```powershell
& .\scripts\start-local-api.ps1
```

启动脚本会把数据库升级到 `20260818_0004`。前端仍使用：

```powershell
& .\scripts\start-local-web.ps1
```

管理员登录后，从左侧进入“套餐管理”。

## 5. 无设备时可以验证什么

- 固定显示五个槽位；
- 显示通知有效期、Token 状态、代金券人工确认状态和激活阻塞原因；
- 显示每个槽位是否在服务端配置；
- 页面不显示完整激活码；
- 没有在线设备时激活按钮禁用；
- 护理人员和家属不能访问页面或接口；
- API、数据库模型、幂等和 Token 重试可通过模拟单元测试验证。

## 6. 取得真实设备后的激活流程

1. 在萤石控制台添加设备或完成设备托管；
2. 在本平台“设备管理”同步设备和通道；
3. 确认设备与通道均在线；
4. 进入“套餐管理”，选择已配置且未使用的槽位；
5. 选择真实设备和在线通道；
6. 勾选风险确认，并在最终确认框再次核对；
7. 提交后查看官方状态码与信息；
8. 只有页面显示“激活成功”且官方码为 `0`，才能将套餐记为成功；
9. `pending`、`rejected` 或 `failed` 均需人工核查，禁止反复点击或改用其他设备试码。

## 7. 状态说明

- `pending`：请求结果未知或处理尚未完成，必须人工核查；
- `succeeded`：官方返回 `activeCode=0`；
- `rejected`：套餐不存在、不匹配、已使用、已过期或无权操作；
- `failed`：网络、Token 缓存或萤石服务异常，不能默认认为未消耗套餐码。

当前没有设备时，本阶段的真实退出条件保持未通过。

## 8. 权益状态判定

页面同时满足以下条件时才显示“可激活”：萤石凭据已配置、Token 已认证、至少配置一个套餐槽位，并且至少有一台已同步的在线设备。缺少任一条件时，页面会显示中文阻塞原因并禁用激活按钮。Token、套餐码和代金券链接不会通过该状态接口返回。
