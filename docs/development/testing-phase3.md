# 第三阶段测试与验收清单

## 自动化范围

后端覆盖：

- Token 状态只返回缓存状态、获取时间和到期时间；
- 激活请求通过 Header 携带 accessToken；
- 激活码只从服务端槽位读取；
- 未确认请求返回 422；
- 未登录返回 401，非管理员返回 403；
- 真实设备、通道与在线状态前置校验；
- 同一槽位和设备通道幂等保护；
- Token 失效后只刷新并重试一次；
- 激活审计记录和脱敏响应；
- 完整激活码不出现在 API 响应中。
- 权益摘要返回 5 个槽位、6 个月通知有效期、Token 状态和可读阻塞项；
- 代金券只返回人工确认布尔状态，不返回领取链接或账户信息。

前端覆盖：

- 加载五个套餐槽位；
- 统计已配置和成功槽位；
- 激活后重新加载审计状态；
- TypeScript 检查和生产构建。

## 运行自动化测试

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
& .\scripts\test-phase3.ps1
```

## 无设备人工验收

1. 重启 API 和前端；
2. 在设备页确认 Token 状态不包含 Token 正文；
3. 打开“套餐管理”，确认显示五个槽位、6 个月通知有效期和 Token 状态；
4. 确认未配置槽位只显示“未配置”；
5. 确认没有在线设备时所有激活按钮禁用；
6. 确认浏览器网络响应中没有 AppSecret、accessToken 或完整套餐码；
7. 使用护理人员账号确认不能访问套餐页面和 API。
8. 尚未领取代金券时确认显示“待人工领取并确认”；领取并在萤石后台核实后，把 `EZVIZ_COUPON_REDEEMED=true` 写入本机 `services/api/.env` 并重启 API，确认页面只显示“已人工确认领取”。

## 真实设备验收门槛

必须取得真实设备后，按照使用说明完成一次正式激活。提交前需要备份套餐清单、核对设备序列号和通道号，并保存脱敏的官方成功证据。没有 `activeCode=0` 时不得宣布第三阶段真实验收完成。
